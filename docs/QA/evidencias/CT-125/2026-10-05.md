# CT-125 — Ninguém envia documento para a conta de outro cliente

- **Data:** 2026-10-05
- **Executor:** usuário (responsável pelo projeto)
- **Commit:** sem commit (pasta sem git)
- **Ambiente:** Windows 10, Docker Desktop (contêiner `rag-postgres`, `pgvector/pgvector:pg17`), aplicação local em `http://localhost:8080`, Postman e `psql`
- **Card / requisito:** HU-006 / RF-006 (CA-03, FA-06); RF-009 CA-02 — prioridade **P1**

## Passos executados

Clientes usados: **Cliente A = id 6** e **Cliente B = id 7** (o roteiro usa 1 e 2; trocar os ids é permitido).

1. `SELECT count(*) FROM document WHERE client_id = 7;`
2. Chave do cliente 6 → `POST /clients/7/documents` com `contrato.pdf` (`CONTRACT`).
3. Chave do cliente 6 → `POST /clients/999/documents`.
4. Chave do administrador → `POST /clients/999/documents` (variação, ver Observações).
5. Contagens depois dos passos, conferidas via `psql`: `client_id = 7` e `client_id = 999`.

## Resultado esperado

Passos 2, 3 e 4 respondem `403`, `title` `Acesso negado`, `detail` `Você não tem permissão para acessar este recurso.` (o mesmo nos três); a contagem do Cliente B não muda.

## Resultado obtido

```text
1. count(*) document client_id = 7  →  0

2. cliente 6 → /clients/7/documents
   403  {"type":"about:blank","title":"Acesso negado",
         "detail":"Você não tem permissão para acessar este recurso.","instance":"/clients/7/documents", ...}

3. cliente 6 → /clients/999/documents
   403  mesma mensagem ("Acesso negado", mesmo detail)

4. administrador → /clients/999/documents
   403  mesma mensagem ("Acesso negado", mesmo detail)

5. count(*) document client_id = 7    →  0  (não mudou)
   count(*) document client_id = 999  →  0
```

## Observações

- **Variação no passo 4:** o roteiro pede que o administrador envie para `/clients/1/documents` (um cliente que existe). O usuário enviou para `/clients/999`. O resultado confirma o que o passo quer mostrar: o administrador não envia documentos (403 com a mesma mensagem). O automático CT-080 (`SecurityConfigTest`, linha "admin no upload de A" da `security-matrix.csv` → 403, OK) cobre o administrador no upload de um cliente que existe.
- O passo 5 não tem print: foi conferido via `psql` em 2026-10-05.
- A mensagem é a mesma para outro cliente que existe (7) e para um que não existe (999): a resposta não revela se o cliente existe.
