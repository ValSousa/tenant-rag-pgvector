## Observações

- Uma primeira versão desta evidência, no mesmo dia, registrou só o passo 2 e o complemento do administrador (execução parcial). O passo 3 e os demais complementos foram entregues depois, ainda em 2026-10-05.
- **Sem chamar o modelo:** o print do passo 3 não prova que o modelo não foi chamado (o tempo aparece cortado, cerca de 2,1 s). Isso é conferido pelo automático CT-070 (`AnswerServiceTest`, sem chunks a resposta é fixa e o modelo não é chamado), que está OK. O CT-114 (P1, `TenantIsolationIT`) confere que o contexto da resposta só tem dados do próprio cliente.
- **Contraste com o Cliente A:** a mesma pergunta para um cliente com documentos é respondida só com os documentos dele (doc 8 e 9, do cliente 6). Esse complemento não substitui o CT-129 (pergunta de perda total para A e B), que segue pendente no HU-008.
- **Pergunta sem relação:** "Qual é o valor da java?" devolve trechos do Cliente A com `score` de até 0,65. Isso segue o RF-007 DP-03 (sem limiar, `minScore = 0`); não é bug. É o exemplo citado no card HU-014 (limiar mínimo de similaridade), criado pelo planejador em 2026-10-05.
- O passo 1 não tem print: foi conferido via `psql`.
