# CT-020 — Administrador cadastra cliente (validação manual)

- **Data:** 2026-10-02
- **Executor:** QA (responsável pelo projeto), pelo Swagger UI
- **Commit:** 997f680 (+ alterações não commitadas do RF-003/RF-004 e da configuração por `.env`)
- **Ambiente:** Windows 10, Docker 29.7.2, JDK 21.0.12, aplicação local em `http://localhost:8080` com banco do `docker compose`
- **Tipo:** complemento manual do CT-020, que é automatizado (`ClientControllerTest`, `ApiFlowIT`; evidência JUnit em [execucoes/2026-10-01-rf-003-rf-004.md](../execucoes/2026-10-01-rf-003-rf-004.md))

## Passos executados

1. Subir o banco (`docker compose up -d`) e a aplicação, com `ADMIN_API_KEY` vinda do `.env`
2. Abrir `http://localhost:8080/swagger-ui.html`
3. Em **Authorize**, informar a chave de administrador (`ADMIN_API_KEY`) no esquema `apiKey`
4. Executar `POST /clients` com um nome de cliente no corpo

## Resultado esperado

- Status 201
- Cabeçalho `Location` igual a `/clients/{id}`
- Corpo com `id`, `name` e `apiKey` não vazia

## Resultado obtido

```text
POST http://localhost:8080/clients  →  HTTP 201
Location: /clients/1
Content-Type: application/json

{
  "id": 1,
  "name": "Teste",
  "apiKey": "*****"   (preenchida na resposta; omitida aqui)
}
```

A `apiKey` devolvida é credencial do cliente e não é gravada em claro; no print ela foi coberta.
