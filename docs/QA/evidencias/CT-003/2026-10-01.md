- **Data:** 2026-10-01
- **Executor:** Claude Code, a pedido do responsável pelo projeto
- **Commit:** 997f680 (+ alterações não commitadas do RF-001)
- **Ambiente:** Windows 10, Docker 29.7.2, JDK 21.0.12

## Passos executados

1. `docker compose up -d`
2. Aguardar o healthcheck do contêiner `rag-postgres`
3. `docker exec rag-postgres psql -U rag -d ragdb -tAc "SELECT extname || ' ' || extversion FROM pg_extension WHERE extname='vector'"`
4. `./mvnw spring-boot:run` (sem variáveis de ambiente: valores padrão de `application.properties`)
5. `curl http://localhost:8080/`
6. Encerrar a aplicação

## Resultado esperado

Contêiner `rag-postgres` healthy, com a extensão `vector`; aplicação sobe conectada ao banco `ragdb` e responde na porta 8080.
