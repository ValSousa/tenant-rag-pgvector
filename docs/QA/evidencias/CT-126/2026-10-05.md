# CT-126 — Reenvio do mesmo arquivo substitui o documento

- **Data:** 2026-10-05
- **Executor:** usuário (responsável pelo projeto)
- **Commit:** sem commit (pasta sem git)
- **Ambiente:** Windows 10, Docker Desktop (contêiner `rag-postgres`, `pgvector/pgvector:pg17`), aplicação local em `http://localhost:8080` com `OPENAI_API_KEY` real, Swagger UI e `psql`
- **Card / requisito:** HU-006 / RF-006 (DP-03, decidida em 2026-10-02) — prioridade P3

## Passos executados

Cliente usado: **Cliente A = id 6** (o roteiro usa 1; trocar os ids é permitido).

1. `SELECT id, client_id, file_name FROM document WHERE file_name = 'contrato.pdf' ORDER BY id;`
2. Reenvio de `contrato.pdf` (`CONTRACT`) pelo cliente 6 em `POST /clients/6/documents`.
3. `SELECT count(*) FROM document_chunk WHERE document_id = 6;` e, via `psql`, o `SELECT` do passo 1 de novo.

## Resultado esperado

`201` com `id` novo; o Cliente A continua com um único `contrato.pdf`, agora com o id novo; o documento antigo não tem mais chunks (contagem `0`); o `contrato.pdf` do Cliente B (se houver) mantém o mesmo id.

## Resultado obtido

```text
1. antes:  id 6 | client_id 6 | contrato.pdf   (único contrato.pdf no banco)

2. reenvio → 201 {"id":9,"clientId":6,"fileName":"contrato.pdf","documentType":"CONTRACT",
                  "createdAt":"2026-10-05T14:18:28.111334Z","totalChunks":2}

3. count(*) document_chunk WHERE document_id = 6  →  0

   depois (psql, 2026-10-05): um único contrato.pdf do cliente 6, agora o id 9 (2 chunks, client_id 6);
   documentos do cliente 6: 7 sinistro.pdf, 8 vistoria.pdf, 9 contrato.pdf
```

## Observações

- O `SELECT` depois do reenvio não tem print: foi conferido via `psql` em 2026-10-05.
- **Cliente B dispensado:** o Cliente B (id 7) não tem `contrato.pdf` próprio, porque o CT-134 não foi executado. A conferência opcional "o `contrato.pdf` do Cliente B mantém o mesmo id" foi dispensada pelo usuário ("Não precisa fazer para o Cliente B"). O automático CT-059 (`DocumentIngestionIT`, OK) cobre esse caso: o reenvio de um cliente não mexe no documento de mesmo nome de outro cliente.
- O cabeçalho `location` não aparece no print (corta antes de **Response headers**); o automático CT-052 confere esse cabeçalho.
