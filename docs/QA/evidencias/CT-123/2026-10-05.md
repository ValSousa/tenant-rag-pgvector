- **Ambiente:** Windows 10, Docker Desktop (contêiner `rag-postgres`, `pgvector/pgvector:pg17`), aplicação local em `http://localhost:8080`, Swagger UI e `psql`
- **Card / requisito:** HU-005 / RF-005 (FA-01); RF-006 FA-04; RF-010 RN-03 — prioridade P2

## Passos executados

Cliente usado: **Cliente A = id 6** (o roteiro usa 1; trocar os ids é permitido).

1. Arquivo de teste: `documento-pdf.pdf`, um arquivo que não é PDF com extensão `.pdf`. Equivale ao `corrompido.pdf` do roteiro; o nome diferente é variação aceita.
2. Swagger UI, chave do cliente 6: `POST /clients/6/documents?documentType=CONTRACT` com `documento-pdf.pdf`.

4. Complementar (executado antes, no mesmo dia): o mesmo envio com `documento.pdf`, um PDF válido sem texto.
